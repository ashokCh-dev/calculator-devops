# Calculator DevOps

A Calculator REST API built with Spring Boot, with a CI/CD pipeline using
Git/GitHub, Jenkins, Docker and Docker Compose.

CSE 816 Software Production Engineering, Mini-Project.

## Planned features

- REST endpoints for add, subtract, multiply and divide
- JUnit 5 and MockMvc tests
- Multi-stage Dockerfile
- Docker Compose deployment behind an Nginx proxy
- Jenkins pipeline: build, test, docker build, push, deploy
